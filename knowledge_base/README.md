# Knowledge base

Для будущего локального импорта распакуйте предоставленный организаторами `knowledge-base.zip` в `source_documents/`. Корпус содержит UTF-8-файлы `.txt` с документами компании, дополнительным соглашением и выдержками из законов.

Имена исходных файлов нужны для ссылок на источники. При импорте разделы и даты следует извлекать из корпуса. Номер страницы сохраняется, только когда его можно установить по источнику.
